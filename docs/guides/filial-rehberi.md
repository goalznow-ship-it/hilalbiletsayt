# Filial rəhbəri üçün təlimat

Filial rəhbəri satıcının bütün imkanlarına (bax [satici.md](satici.md)) malikdir
və əlavə olaraq öz filialında aşağıdakıları edir.

## Gündəlik nəzarət

* **Bilet satışı** — filialın bütün satışları, ödəniş vəziyyəti.
* **Hesabatlar** — statuslar və ödənişlər üzrə yekunlar (yalnız öz filialınız).

## Günün bağlanması

1. İş günü bitəndə **Günün bağlanması** bölməsini açın. Tarix Bakı vaxtı ilə
   götürülür.
2. Satılan bilet, ödənilib, ödəniş gözlənilir, ləğv edilib və kassa
   məbləğini kassadakı nağd pulla müqayisə edin.
3. Ödənişi gözlənilən biletləri yoxlayın: ya ödənişi təsdiqləyin, ya da satıcı
   bileti ləğv etsin.
4. **Günü bağla** düyməsini basın və təsdiqləyin.

Bağlandıqdan sonra həmin günün satışları **dondurulur**: yeni satış, ödəniş
təsdiqi, ləğv və ya dəyişiklik mümkün deyil. Yalnız imtahan günü girişdə
qəbul (QR yoxlama) işləyir. Bağlanmış günü yenidən açmaq olmur; səhv sonrakı
gündə ayrıca əməliyyatla düzəldilir və yazılı izah edilir. Keçmiş günü də
(bağlanmamışsa) tarixi seçib bağlaya bilərsiniz; gələcək günü bağlamaq olmaz.

## OMR və cavab vərəqləri

Filial rəhbəri öz filialının ödənilmiş biletləri üçün cavab vərəqi yarada,
skanları yükləyə və yoxlama növbəsini işləyə bilər. Ətraflı:
[netice-operatoru.md](netice-operatoru.md).

## Namizədlər

**Namizədlər** səhifəsində (`/candidates`) filialınıza aid namizədləri görür və redaktə
edirsiniz. Başqa filialın namizədləri sizə görünmür.
